# Portafolio · Andrés Caicedo (andresc_productions)

Portafolio de diseño digital, audiovisual y arte plástico, con sala de ventas.

## Publicar en GitHub Pages
1. Sube todos los archivos de esta carpeta a la raíz del repositorio (la carpeta, no el ZIP).
2. En el repositorio: **Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)`** y guarda.
3. En 1–2 minutos queda en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.

La página de inicio es `index.html`. No requiere instalación ni compilación.
